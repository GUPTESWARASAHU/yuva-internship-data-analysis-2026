# Week 1 – Data Exploration and Problem Definition

## Objective

The objective of Week 1 was to explore a publicly available dataset,
understand its structure and data quality, identify important variables,
perform exploratory data analysis and define an analytical problem.

## Dataset

Online Retail Dataset

The dataset contains transaction-level information including:

- Invoice number
- Stock code
- Product description
- Quantity
- Invoice date
- Unit price
- Customer ID
- Country

## Analysis Performed

- Dataset structure analysis
- Data type identification
- Missing-value analysis
- Duplicate detection
- Cancellation analysis
- Revenue analysis
- Product analysis
- Customer analysis
- Country analysis
- Monthly revenue analysis
- Outlier investigation
- Data visualization

## Key Results

Total records: 541,909

Total revenue from sales records: £10,644,560.42

Total transactions: 22,064

Identified customers: 4,339

Repeat customer percentage: 65.57%

Highest revenue country: United Kingdom

Highest revenue month: November 2011

## Problem Definition

The analysis aims to understand sales performance, product demand,
customer purchasing behavior, geographical distribution and transaction
quality in the online retail dataset.

## Tools

Python, Pandas, NumPy, Matplotlib, Seaborn and Google Colab.
