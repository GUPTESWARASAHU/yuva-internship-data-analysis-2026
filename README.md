## 📊 Week 1 – Online Retail Data Analysis

### Objective

Explore a publicly available online retail transaction dataset,
understand its structure and data quality, identify important variables,
discover initial patterns and define a clear analytical problem.

### Dataset

Online Retail transaction dataset.

### Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Key Findings

- Total records: 541,909
- Sales records after separating cancelled records: 532,621
- Total revenue: £10,644,560.42
- Transactions: 22,064
- Unique products: 4,059
- Identified customers: 4,339
- Average order value: £482.44
- Repeat customer percentage: 65.57%
- Top 10 customer revenue share: 17.26%
- Highest revenue country: United Kingdom
- Highest revenue month: November 2011
- Lowest revenue month: February 2011

### Data Quality

The dataset contains:

- 135,080 missing CustomerID values
- 1,454 missing descriptions
- 5,268 duplicate records
- 9,288 cancelled transactions
- 10,624 non-positive quantity values
- 2,517 non-positive unit-price values

### Problem Definition

The project aims to analyze historical online retail transaction data
to identify patterns in sales performance, product demand, customer
purchasing behavior, geographical distribution and transaction quality.
